# cld-

A collection of tools, utility apps, and CLI utilities.

## Purpose

This repository serves as a home for small, focused tools and utilities built to solve specific problems. Projects range from command-line interfaces to standalone utility apps, each designed to be practical and reusable.

## Scope

- **CLI tools** — command-line utilities for automation and productivity
- **Utility apps** — small applications that do one thing well
- **Shared helpers** — common functions and modules reused across tools

Each tool lives in its own directory with its own usage instructions.
